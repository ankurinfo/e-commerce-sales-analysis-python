# E-Commerce Sales Data Analysis & EDA Using Python

## Project Overview
This project focuses on Exploratory Data Analysis (EDA) of e-commerce sales data using Python. The goal is to understand customer behavior, analyze product performance, identify sales trends, and generate useful business insights.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Key Analysis
- Dataset overview and data quality assessment
- Missing values and duplicate records
- Descriptive statistical analysis
- Customer analysis by city and customer segment
- Product performance analysis
- Sales analysis
- Time-based sales analysis
- Correlation analysis

## Project Files
- `e-commerce-sales-analysis-eda-using-python.ipynb` — Jupyter Notebook containing the analysis.
- `sales.csv` — Dataset used in the project.

## Objective
To practice Python-based data analysis and transform raw sales data into meaningful insights that can support business decision-making.

## How to Run
1. Clone or download this repository.
2. Install the required libraries:
   `pip install pandas numpy matplotlib seaborn jupyter`
3. Place `sales.csv` in the project folder.
4. Open the notebook in Jupyter Notebook or VS Code.
5. Run the cells to explore the analysis.
